# Kobrowse

Kobrowse — файловый менеджер для ридеров Kobo с Qt 5. Он открывается из
NickelMenu и предназначен для работы с файлами в памяти устройства.
Интерфейс адаптирован для чёрно-белого экрана и сенсорного управления.

## Возможности

- Просмотр файлов и папок, переход к родительской папке и отображение пути.
- Дата изменения и размер файлов, отображение скрытых элементов.
- Выбор элементов долгим нажатием, копирование, перемещение и корзина.
- Создание и распаковка ZIP, поиск книг, настройки интерфейса и открытие книг на
  поддерживаемых прошивках.

Проект находится в разработке. Перед тестированием сохраните резервную копию
книг и других важных данных. Совместимость с конкретной моделью и прошивкой
необходимо проверить на устройстве.

## Установка

1. Установите [NickelMenu](https://github.com/pgaskin/NickelMenu) на Kobo.
2. На странице успешного запуска [GitHub Actions](https://github.com/Mutaracha/Kobrowse/actions/workflows/kobo-test.yml)
   скачайте артефакт `kobrowse-kobo-qt5-test` и извлеките из него архив
   `KoboRoot.tgz`.
3. Подключите ридер к компьютеру. Если в папке `.kobo` уже есть ожидающий
   установки `KoboRoot.tgz`, сначала разберитесь с ним и сохраните его копию.
4. Скопируйте `KoboRoot.tgz` в папку `.kobo` на ридере.
5. Безопасно извлеките устройство и дождитесь установки. Откройте пункт
   **«Файлы»** в NickelMenu.

При переходе с предыдущего прототипа удалите его плагин и пункт меню отдельно,
чтобы не запускать два менеджера одновременно. Новая версия использует свои
пути настроек и корзины; прежние настройки и файлы в корзине автоматически не
переносятся и не удаляются. Сохраните их резервную копию перед переходом.

## Использование

Короткое нажатие открывает папку, книгу или архив; долгое нажатие выбирает элемент
для операций. Для создания архива отметьте один или несколько элементов и
нажмите **«В ZIP»**: архив появится в текущей папке, исходники останутся на
месте. При совпадении имени выбирается новое. Кнопки внизу позволяют листать список, подниматься по
каталогам, открыть поиск и настройки. Папка просмотра по умолчанию —
`/mnt/onboard`.

Настройки создаются при первом запуске в
`.adds/kobrowse/kobrowse.ini`, журнал — в `.adds/kobrowse/kobrowse.log`.
Удалённые через приложение элементы перемещаются в `.kobrowse_trash` в корне
пользовательского накопителя. Пакет установки не перезаписывает настройки.

Список читается непосредственно с накопителя и не использует правило
`ExcludeSyncFolders` из настроек индексации Nickel. Для отображения файлов и
папок с точкой включите **Настройки → Скрытые файлы → показывать** (это
значение по умолчанию). Отображаются доступные файлы, кроме временных файлов
приложения; поиск книг пока исключает скрытые пути. Изменять конфигурацию
индексации Kobo для просмотра не требуется.

Символические ссылки отображаются, но переход и операции через них запрещены.
Служебные папки `.kobo`, `.adds` и корзина доступны для просмотра, но защищены
от изменения через файловые операции. Создание архива использует сжатие ZIP32: предел — менее 4 ГиБ на файл и
архив и не более 65 535 записей. Ссылки и служебные папки не архивируются;
при ошибке временный архив удаляется. Большие архивы создаются синхронно и
могут надолго занять интерфейс. Будьте осторожны при распаковке: защита от
опасного содержимого ZIP ещё не завершена.

Если скрытые папки не отображаются при включённой настройке, откройте корень
`/mnt/onboard` и проверьте строку `root listing` в журнале
`.adds/kobrowse/kobrowse.log`. Она показывает, видят ли Qt и системное чтение
каталога папки `.adds` и `.disabled`; другие имена файлов не записываются.
