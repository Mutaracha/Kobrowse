# Kobrowse

Kobrowse — файловый менеджер для ридеров Kobo с Qt 5. Он открывается из
NickelMenu и предназначен для работы с файлами в памяти устройства.
Интерфейс адаптирован для чёрно-белого экрана и сенсорного управления.

## Возможности

- Просмотр файлов и папок, переход к родительской папке и отображение пути.
- Дата изменения и размер файлов, отображение скрытых элементов.
- Выбор элементов долгим нажатием, копирование, перемещение и корзина.
- Поиск книг, распаковка ZIP, настройки интерфейса и открытие книг на
  поддерживаемых прошивках.

Проект находится в разработке. Перед тестированием сохраните резервную копию
книг и других важных данных. Совместимость с конкретной моделью и прошивкой
необходимо проверить на устройстве.

## Установка

1. Установите [NickelMenu](https://github.com/pgaskin/NickelMenu) на Kobo.
2. На странице успешного запуска [GitHub Actions](https://github.com/Mutaracha/Kobrowse/actions/workflows/ci.yml)
   скачайте артефакт `kobrowse-kobo-qt5-test` и извлеките из него архив
   `kobrowse_KoboRoot.tgz`.
3. Подключите ридер к компьютеру. Если в папке `.kobo` уже есть ожидающий
   установки `KoboRoot.tgz`, сначала разберитесь с ним и сохраните его копию.
4. Скопируйте скачанный архив в папку `.kobo` на ридере под именем
   `KoboRoot.tgz`.
5. Безопасно извлеките устройство и дождитесь установки. Откройте пункт
   **«Файлы»** в NickelMenu.

При переходе с предыдущего прототипа удалите его плагин и пункт меню отдельно,
чтобы не запускать два менеджера одновременно. Новая версия использует свои
пути настроек и корзины; прежние настройки и файлы в корзине автоматически не
переносятся и не удаляются. Сохраните их резервную копию перед переходом.

## Использование

Короткое нажатие открывает папку, книгу или архив; долгое нажатие выбирает элемент
для операций. Кнопки внизу экрана позволяют листать список, подниматься по
каталогам, открыть поиск и настройки. Папка просмотра по умолчанию —
`/mnt/onboard`.

Настройки создаются при первом запуске в
`.adds/kobrowse/kobrowse.ini`, журнал — в `.adds/kobrowse/kobrowse.log`.
Удалённые через приложение элементы перемещаются в `.kobrowse_trash` в корне
пользовательского накопителя. Пакет установки не перезаписывает настройки.
Будьте осторожны при работе с архивами и символическими ссылками.
