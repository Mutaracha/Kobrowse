# Тестовая сборка и происхождение артефакта

`scripts/build-kobo.sh` использует образ NickelTC по неизменяемому digest
`ghcr.io/pgaskin/nickeltc@sha256:3296eb400d270cfd26f5773ab09625d4469f85680b3a191951dfb78d8ade7840`.
Digest получен из тега `:1` после успешной сборки в CI
[45996277964](https://github.com/Mutaracha/Kobrowse/actions/runs/45996277964).
Изменение digest требует отдельной проверки сборки и совместимости на Kobo.
Образ содержит прежний SDK; перенос на другой SDK не производился.

Перед запуском сборки скрипт удаляет только генерируемые `libkobrowse.so`,
`build/KoboRoot.tgz` и `build/build-info.json`. Компиляция принудительная
(`make -B all`); после упаковки проверяется состав архива и побайтовое
совпадение библиотеки внутри него с полученной библиотекой. При ошибке команда
возвращает ненулевой код и CI не публикует артефакт. Отдельный вызов
`make package` не даёт этих гарантий.

После проверки создаётся `build/build-info.json` рядом с `KoboRoot.tgz`:
- Git commit Kobrowse и NickelHook, состояние незакоммиченных изменений;
- запрошенный идентификатор SDK, обнаруженные Docker repository digests и ID;
- SHA-256 пакета и библиотеки, время создания метаданных в UTC.

CI требует чистые исходники и соответствие commit значению `GITHUB_SHA`;
локальная сборка допускает изменения и отмечает их как `dirty`. Одна только
ревизия не описывает содержимое изменённого рабочего дерева. `KOBROWSE_SDK_IMAGE`
позволяет явно выбрать другой SDK, который будет указан в метаданных; такая
сборка не считается проверкой закреплённого образа. `CONTAINER_ENGINE` задаёт
движок с совместимыми командами `run` и `image inspect`.

Артефакт Actions содержит `KoboRoot.tgz` и `build-info.json`; устанавливается
только первый. Для проверки целостности файла можно сравнить результат команды
`sha256sum KoboRoot.tgz` с полем `files.KoboRoot.tgz.sha256` в метаданных.
Метаданные не подписаны и не являются независимой аттестацией; закрепление SDK
и запись хешей не доказывают побайтовую воспроизводимость сборки или работу
на реальном устройстве. Необходимы резервная копия и проверка на Kobo.
