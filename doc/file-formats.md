# Значки типов файлов

Классификация относится только к отображению: она не добавляет поддержку
открытия файлов в Nickel или Kobrowse. Список зависит от версии прошивки и на
Kobo Libra 2 / Glo HD с 4.38.23697 пока не проверен.

[Официальная справка Kobo](https://help.kobo.com/hc/en-us/articles/360017763713-File-formats-your-Kobo-eReader-and-Kobo-Books-app-support)
перечисляет EPUB, PDF, FlePub, MOBI, JPEG, GIF, PNG, BMP, TIFF, TXT, HTML,
RTF, CBZ и CBR для eReader. Для видимых значков используются суффиксы:

* книга: epub (включая kepub.epub), pdf, mobi, txt, html, htm, rtf, fb2;
* изображение: jpg, jpeg, gif, png, bmp, tif, tiff;
* архив: zip, rar, 7z, tar, gz, cbz, cbr.

FB2 и общие архивы включены как распространённые типы файлов, не как обещание
поддержки Nickel; CBZ/CBR показываются архивом. FlePub не сопоставлен суффиксу
без надёжного подтверждения. Распаковка ZIP в Kobrowse остаётся отключённой.
